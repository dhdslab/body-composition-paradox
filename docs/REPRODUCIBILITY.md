# Reproducibility

## Environment of the study

- Windows 11, Python 3.12.14 with the versions pinned in `requirements.txt`
  (NumPy 2.5.3, pandas 3.0.6, SciPy 1.18.1, scikit-learn 1.9.1, statsmodels 0.15.0)
- Four threads for BLAS and OpenMP (`OMP_NUM_THREADS`, `OPENBLAS_NUM_THREADS`, `threadpoolctl`)

## Determinism

Every result is a fixed-seed computation; re-running the same code on the same raw files gives the same
numbers.

- Gradient boosting (`random_state`), the 2024 cross-validation folds (`GroupKFold(shuffle=True)`) and
  the Rao–Wu bootstrap all use seed 927 (`common.SEED`).
- `replicate_factors` starts a new generator with that seed on every call, so the replicates of a
  given sampling frame do not depend on the order in which the steps run.
- Hyperparameters are fixed in `common.reg` and `common.clf`. The tuning periods select only the model
  family.

## What the committed results are

`results/` was produced from the study data: `cohort_flow.csv` and `predictor_missingness.csv` by
step 01 from the KNHANES raw files, and everything else by steps 02–13 from the dataset written by step
01, run in a clean directory with this code.

Checks made on the study data before release:

- Every CSV in `results/tables/` and `results/source_data/` is identical, cell by cell, to the output
  of the analysis code used for the manuscript. The one exception is `source_data/Fig1.csv`, which no
  longer lists a note box that was dropped from the submitted Fig. 1.
- Figs 2–6 and Supplementary Figs 1–4 are byte-identical to the submitted image files, and every sheet
  of `Supplementary_Data_1.xlsx` matches the submitted Supplementary Data 1.
- Step 01 was checked without the raw files by rebuilding per-year files from the analysis dataset.
  Every transformation in step 01 leaves such rows unchanged, and it returned the dataset exactly
  (101,789 rows × 224 columns).

## Check the code against the committed results

```bash
BCP_RESULTS=results_regen python run_all.py        # PowerShell: $env:BCP_RESULTS = "results_regen"
python check_reproduction.py results_regen
```

This needs the raw data (see the main [README](../README.md#data)). It writes to `results_regen/` and
leaves `results/` untouched, then compares every table and source-data file cell by cell (numbers to a
relative tolerance of 1e-9, text exactly).

## Notes

- Step 01 inventories every annual (`*_all`) and DXA (`*_dxa`) file in `data/KNHANES/`. The 49
  current-disease items are those present in the 2008–2024 files.
- The figures in `results/figures/` are drawn by step 12. The submitted Fig. 1 was laid out from this
  draft, with the same numbers.
- Steps 05 (diagnosis-related biomarkers), 06, 07, 09 and 10 and the 2024 refitting in step 03 were
  added after the initial results and are post hoc.
